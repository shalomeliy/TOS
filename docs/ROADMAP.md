# מפת גרסאות - TOS Trainer (בסגנון N4)

20 גרסאות. כל גרסה מלמדת רעיון אחד של מערכת ניהול נמל, ונבנית על הקודמת.
הסטטוס העדכני של כל גרסה נמצא ב-`HANDOFF.md`. המסמך הזה הוא התוכנית, לא היומן.

**סדר העבודה בכל גרסה** (לפי `CLAUDE.md`):
מסמך דרישות (`docs/specs/`) -> אישור שלך -> ניסוי קטן (spike) כשיש סיכון -> תוכנית (`docs/plans/`) -> אישור -> בנייה ובדיקה (`node tools/smoke.mjs`) -> עדכון `HANDOFF.md` -> commit -> הוראות בדיקה בשבילך.

**כללים קבועים:** קוד מקורי בלבד, בלי קוד או מסכים של Navis/Kaleris. המראה "בסגנון N4", לא העתק. כל מסך מקבל הסבר קצר בעברית.
